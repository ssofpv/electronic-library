# 📚 Веб-приложение «АИС Библиотека»

Электронная библиотека — это автоматизированная информационная система (АИС) каталогизации книг, разработанная в качестве экзаменационного проекта. Приложение позволяет управлять каталогом литературы, осуществлять гибкий поиск, фильтрацию, а также оставлять рецензии к книгам с поддержкой форматирования текста.

---

## 🛠️ Технологический стек

* **Backend:** Python 3.10+, Flask
* **Database:** SQLAlchemy (SQLite)
* **Frontend:** HTML5, CSS3, JavaScript
* **Дополнительные библиотеки:** Flask-Login (авторизация), Markdown/Bleach (обработка и безопасный вывод рецензий)

## 🚀 Основной функционал

1. **Каталог книг:** Отображение доступной литературы с обложками.
2. **Поиск и фильтрация:** Динамический фильтр по названию, автору, жанрам, году издания и количеству страниц.
3. **Интерактивные рецензии:** Возможность написания отзывов авторизованными пользователями с использованием встроенного визуального Markdown-редактора.
